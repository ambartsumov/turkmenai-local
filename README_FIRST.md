TurkmenAI Local — локальная AI-платформа. Этот выпуск является **production-oriented 0.1.0**, а не заявкой на stable `1.0.0`: в нём есть реальные Linux installer-артефакты, локальное ядро, storage, планировщик и API, но отсутствует преднастроенный, проверенный runtime с моделью для гарантированной inference из коробки.

## Для обычного пользователя

| Шаг | Действие |
|---|---|
| 1 | Откройте `installers/linux/` и выберите реальный пакет для вашей Linux-системы: AppImage, DEB или RPM. |
| 2 | Сверьте SHA-256 из `checksums/sha256sums.txt` до установки. |
| 3 | Установите приложение и откройте Local Console. Она покажет фактический профиль оборудования только в native-приложении. |
| 4 | До появления проверенной runtime-интеграции используйте безопасные функции: hardware report, model analysis, execution plan и Model Doctor. |
| 5 | Прочитайте `documentation/KNOWN_LIMITATIONS.md`, прежде чем ожидать inference, загрузку модели или LAN-sharing. |

Ни терминал, ни Python не требуются для установки реального Linux-пакета. Терминал нужен лишь разработчикам и опытным пользователям для текущего `tmai` CLI.

## Правило безопасности

Не запускайте скрипты из model repository только потому, что источник просит `trust_remote_code`. TurkmenAI Local специально относится к этому как к явному security state.
