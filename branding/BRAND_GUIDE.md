# TurkmenAI Local — Brand Guide

TurkmenAI Local uses the **«Горный сигнал»** system: a practical technical identity built around the idea of computation that remains close to the user. The mark combines a containment frame, a quiet ridgeline and an active signal path. It is intentionally geometric rather than decorative; the Turkmen reference comes from landscape rhythm, proportion and the restrained cyan/sand contrast rather than literal symbols.

| Component | Token | Intent |
|---|---|---|
| Foundation | `#06101B` | Local infrastructure, depth, privacy and focus. |
| Signal | `#31D8C7` | An active but precise local capability, never a decorative gradient. |
| Sand | `#D9C6A4` | A warm human counterweight used sparingly for hierarchy. |
| Fog | `#EDF1ED` | High-legibility editorial surface in light contexts. |
| Display/body | Manrope | Compact, serious and readable for Russian, Turkmen Latin and English. |
| Technical labels | Space Mono | Traceable state, commands, paths and version indicators. |

The primary wordmark is typeset as **TurkmenAI Local**, with `TurkmenAI` in Manrope ExtraBold and `Local` in the Signal color at a lighter weight. It must never be replaced by a generic default font. The generated transparent PNG is used for web headers and the platform icon family. The SVG variants are deterministic source assets for print, monochrome UI, and constrained installer contexts.

The identity does not use national flags, ornamental patterns, purple gradients, or gaming visual language. A visual choice is accepted only when it reinforces autonomy, clarity and engineering trust.
