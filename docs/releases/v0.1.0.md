# TurkmenAI Local `v0.1.0`

> **Experimental Linux technical release — not a stable general-availability release.**

## Highlights

This first public source and Linux package release establishes the local-first platform foundation: model-source analysis without executing repository code, hardware-aware execution planning, SHA-256 model storage, resumable HTTP Range downloads, versioned local state, an English-first desktop console with Russian and Turkmen UI, and a private loopback API.

The desktop shell can discover and start an explicitly chosen local `llama-server`, bind it to `127.0.0.1`, require its `/health` readiness response, and forward OpenAI-compatible requests only after that verification. No cloud inference, telemetry or LAN sharing is enabled by default.

## Platform status

Windows x64/ARM64, Linux ARM64 and macOS Intel/Apple Silicon are CI targets, not release assets. They are not claimed as available until their native runner builds and install smoke tests have passed.

## Important limitations

No runtime or model is bundled. The chat endpoint intentionally returns `NO_ACTIVE_RUNTIME` until the user supplies an existing local `llama-server` executable and a compatible GGUF model and the runtime health check succeeds. A completed model browser, beginner download/install flow, model switching UI, full chat UI, cross-platform installer tests and independent security review are not part of this release.
