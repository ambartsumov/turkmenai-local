# Privacy Policy — Software Behaviour

TurkmenAI Local is designed to keep local AI operations on the device. In `0.1.0`, telemetry, cloud inference, model uploads, LAN sharing and remote inference are disabled by default. The local HTTP API binds to `127.0.0.1`.

Model download is an explicit user-directed network action. The current software does not include an automatic registry update or background cloud request. Diagnostic export is local and intended to be reviewed before sharing. This document describes the implemented application behaviour, not a substitute for jurisdiction-specific legal advice.
